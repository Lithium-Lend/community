# Lithium Community

The public forum for Lithium users, developers, and ecosystem partners.

## Discussions

Use [Lithium Discussions](https://github.com/Lithium-Lend/community/discussions)
for:

- protocol and product proposals;
- integration and developer questions;
- market and ecosystem conversation;
- release announcements; and
- community projects.

Use repository issues for reproducible bugs and scoped implementation work.
Report vulnerabilities privately through the affected repository's Security
tab.
